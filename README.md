# Malaysia — Truly Asia

A single-page website introducing Malaysia across 12 topics (country overview, population, languages, political leadership, cultural festivals, traditional sports, local entertainment, traditional dress, health and wellness, personality, communication, environment). Each topic includes real photos (Wikimedia Commons, credited) and an embedded YouTube video.

Plain HTML/CSS/JS, no build step.

- `index.html` — page structure and content
- `styles.css` — design system (colors, type, layout)
- `script.js` — mobile nav toggle + scroll-spy active link highlighting

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000
